# 两分钟演示：从一组条件到下一次实验

先按README生成2000行synthetic、运行import_nasa.py加入11条真实观测、训练20成员mixed模型，再启动8000端口服务。

```powershell
.\.venv\Scripts\python.exe scripts/demo.py
```

脚本会真实调用所有新接口，并将请求、完整响应、请求ID和耗时写入
`artifacts/demo_report.json`。界面仍由前端队友开发，下面说明可以直接转为五个演示面板。

1. **展示真实数据与可复核身份。** `GET /datasets`显示183条NASA证据及逐条来源/排除原因，只有11条完整记录标记为已用于模型。`GET /model-card`显示2011行、21组、mixed来源、5.18秒标签窗和按source评估。展开四类指纹和GroupKFold编号；NASA整篇报告只算1保守组。
2. **比较任务大气。** `POST /predict/batch` 比较棉织物在21%/101.3kPa与34%/56.5kPa、相同气流下的预测。同时显示条件速度区间、熄灭概率与数据支持标记，保留模型会外推的事实。
3. **把预测扩展为可解释研究报告。** `POST /analyze` 返回5材料、4情景、3个控制参数低/高端的变化，以及±1个百分点氧气、±2kPa、±1cm/s下128个随机点和8角点的结果。演示材料厚度不同、参数扰动是否会让燃烧判定翻转。
4. **寻找值得测试的改动。** `POST /optimize` 扫描1000格点加当前条件；对支持域候选检查全部8个邻域角点。默认例子找到5个目标匹配方案，显示最小调参成本和Pareto前沿。U形两侧都搜索；中心达到目标但邻域不满足的方案不会混入结果。目标是经验成员下分位≥0.9，不是“90%保证安全”。
5. **把科学问题交给下一次实验。** `POST /experiments/design`显示信息代理、预测熵、成员内熵、测试距离和得分分解。v0.3固定演示首个候选约42.95%O2、56.5kPa、0.10cm/s，信息代理约0.161bits；这是模型建议，尚未实际执行或测量收益。必须显示外推标记。

本机正式v0.3完整HTTP耗时：场景报告约51ms、默认约束搜索约499ms、实验设计约147ms；50×50地图冷请求中位数约221ms。测量会随硬件负载变化；使用 `scripts/benchmark_map.py`复测。

答辩需要明确讲清：

- 正速度指“如果火焰持续存在”，熄灭概率独立给出；不能把正速度直接当作持续燃烧结论。
- 成员全部说“不燃”也可能是外推的一致错误，因此始终展示支持域和模型卡限制。
- 输入扰动分布与成员离散属于不同来源的不确定性，均不等于已经校准的联合安全保证。
- 当前mixed模型含11条真实NASA观测。NASA整篇留出时速度区间覆盖率37.5%，不能使用聚合93.48%冒称NASA已可靠；这正是后续独立实验需要解决的迁移问题。
- 前端仍可继续使用原有v1接口；新增能力的请求和响应约定见 [ADVANCED_API.md](ADVANCED_API.md)。
