# 可复核的假设与近似常数

当前v0.3为2000条synthetic＋11条真实NASA观测的mixed研究模型。本表解释近似物理与生成器部分；所列热物性/边界尚未完成真实实验标定。NASA原始测量与人工近似分开记录，见 [NASA_DATA.md](NASA_DATA.md)。单位换算、π和标准正态分位属于数学定义，其余选择不能当作认证安全参数。

## 物理基线：`physics/flame_spread.py::CONSTANTS`

热薄材料对向流热平衡的启发式表达式：

```text
V_potential [m/s] = (π/4) k_g max(T_f - T_v, 25)
                    / [ρ_s c_s τ (T_v - T_inf)] × (P / 101.3)^0.15
T_f [K] = 900 + 35 × O2_percent
LOC [%] = L_material - 2 ln(P / 101.3) + 1.2 ln(thickness_mm / 0.2)
          + 14 / (flow_cm_s + 0.4) + 0.6 (flow_cm_s / 10)^1.5
```

| 常数/选择 | 值 | 含义 |
|---|---:|---|
| C | π/4 | 按需求采用的热平衡系数 |
| 气相有效导热率 | 0.04 W/(m·K) | 假设为常数，忽略组分、温度依赖 |
| 环境温度 | 293.15 K | 不作为 API 自由变量 |
| 火焰温度截距/斜率 | 900 K、35 K/氧百分数 | 简单线性示意；高氧外推不代表真实平衡火焰温度 |
| 最低火焰过热度 | 25 K | 数值保护，使潜在速度为正 |
| 参考压力 | 101.3 kPa | 速度与氧极限修正的参考值 |
| 速度压力指数 | 0.15 | 温和增强，未标定 |
| 氧极限压力系数 | 2 个百分数单位 | 压力升高时降低氧极限 |
| 参考厚度 | 0.2 mm | 厚度对氧极限的对数修正基准 |
| 氧极限厚度系数 | 1.2 个百分数单位 | 忽略厚材料内部导热细节 |
| 低流淬熄系数/流速偏置 | 14、0.4 cm/s | 低流氧输运及辐射损失的合并示意 |
| 高流吹熄系数/标度/指数 | 0.6、10 cm/s、1.5 | 有限停留时间的合并示意 |
| m ↔ mm | ×1000 / ÷1000 | 厚度先转换为 m，速度再转换为 mm/s |

上述 LOC 的最小值对应 `flow≈11.6142127625 cm/s`，由该假定曲线的导数求根得到，不是实验测量。O2≥LOC 为 burning，低于全局最小 LOC 为 no_ignition，其余按最优流速左右分成 quench/blowoff。

`V_physics` 在熄灭区门控为 0；残差与物理 log 特征使用始终为正的 `V_potential`，允许机器学习纠正物理门控。忽略舱体几何、热辐射的显式方程、点火能量、燃烧化学、重力残余和材料退化；厚 PMMA 超出热薄假设。

本实现τ使用API输入的全厚度；部分原始deRis推导使用半厚度。这里始终是启发式基线，并未宣称逐项复现文献公式；不能为改善某张真实测试表的分数而暗改厚度定义。

## 合成数据：`data/synthetic.py::ASSUMPTIONS`

- 默认 seed=42、2000 行、20 组，每组一种材料、覆盖一个参数矩形。
- 对数速度独立噪声 σ=0.12，实验批次偏移 σ=0.06。
- 厚度为库默认值乘 N(1,0.06)，乘数截断在 [0.8,1.2]。
- 隐藏对数偏差：`0.32 sin(O2/9) + 0.24 cos(ln(1+u)) + 0.22 ln(P/80) + 0.10 ln(ρ/550) + batch_offset`。
- 隐藏边界偏移：`1.8 sin(ln(1+u)) + 0.8 cos(O2/10) + 0.6 ln(P/80)`。
- 不持续燃烧概率：`sigmoid((boundary_bias - physics_o2_margin)/1.2)`，再随机抽取结果。
- 未持续燃烧行的点火概率：`sigmoid((O2 - minimum_LOC + 3)/1.5)`；持续燃烧行必已点火。
- sigmoid 输入截断至 [-40,40] 防止数值溢出。
- 刻意不采样 `O2>32%, P>95kPa, u>35cm/s` 的交集，演示空洞与外推。
- gravity_g=0；source=synthetic；非持续燃烧速度留空。

| 参数区域 | O2 % | P kPa | u cm/s（对数均匀） |
|---|---|---|---|
| 1 | 12–26 | 80–115 | 0.15–12 |
| 2 | 18–35 | 45–80 | 3–35 |
| 3 | 22–45 | 65–105 | 20–100 |
| 4 | 14–40 | 90–120 | 1–25 |

人工真值刻意接近物理基线但带平滑偏差，利于演示残差学习；因此混合模型在合成数据中的优势不能直接推断到真实数据。

## 模型、区间和数据支持：`models/residual_ensemble.py`

| 选择 | 默认值 |
|---|---|
| 回归器/分类器数量 | 各 20，按整个 experiment_id 有放回抽组 |
| 每成员树数/学习率/叶数 | 100 / 0.05 / 15 |
| min_child_samples / L2 reg_lambda | 15 / 1.0 |
| 线程数/随机性 | n_jobs=1，deterministic=True、force_col_wise=True，seed+member |
| bootstrap 重试上限 | 200，确保有燃烧回归样本及分类双类别 |
| 回归目标 | 混合：ln(V)-ln(V_potential)；纯 ML：ln(V) |
| 物理 regime 编码 | burning=0、quench=1、blowoff=2、no_ignition=3 |
| 速度区间正态分位 z | 1.6448536269514722（双侧名义90%） |
| log 噪声标准差下限 | 0.03 |
| 最大训练 gravity_g | 0.01；超过即拒绝 |
| log 速度数值截断 | [-30,30] |

只用训练组中整组未被某成员抽中的 OOB 样本估计误差。噪声方差约为 `mean(OOB_log_error²)-mean(OOB_member_variance)`，最低取 0.03²；若极小集成没有 OOB 误差，则内部按整组留一拟合临时回归器。它是经验估计，不是已证明覆盖的校准算法。

预测速度是成员 `V_potential×exp(residual)` 的算术平均。区间以平均 log 速度为中心，log 方差为成员 log 方差加上述噪声方差，再取 exp，并包住算术均值。分类输出为成员 P(extinction) 的算术平均；`uncertainty` 为这些概率的总体标准差；`extinction_ci` 为成员的 5%–95% 分位并包住平均值。

数据支持按材料分别建立最近邻索引，使用 `[O2/20, P/50, ln(1+u)/ln101, thickness/(0.6×library_thickness)]` 坐标。距离阈值是训练点留一最近邻距离的 95% 分位，倍数=1，截断至 [0.08,0.22]；同时要求四个输入处于该材料实测 min/max 内。无该材料的支持时距离占位为 2、范围判断 false。这是支持域启发式，不是严格统计置信域。

## 分组验证：`models/train.py`

- GroupKFold 5 折，shuffle=True、seed=42，打乱整组而不拆行；每折保存训练与测试 ID。
- 三模型完全共享外层折；预处理、支持域及 OOB 噪声只在外层训练组拟合。
- 纯物理分类概率为 `sigmoid(-physics_o2_margin/1.2)`，sigmoid 指数截断 [-40,40]；不声称概率已校准。
- 对数指标仅在观测持续燃烧行计算，所有模型比较门控前的条件速度；数值 log 下限 1e-8。
- 速度区间覆盖率仅统计上述燃烧行；物理无区间，覆盖率为 null。
- 分类指标在全部折外行计算。单类别数据不能用于训练当前分类器；ROC-AUC 在没有双类别时无定义。

## 地图、推荐、解释与展示阈值

- 地图默认 50×50、O2=[12,40]、u=[0.5,100] cm/s，气流对数等距；允许5–100分辨率。LRU 缓存32个请求；结果拷贝避免污染。
- P(extinction)=0.5 沿每一 flow 行插值，多次交叉取最高 O2；范围内无交叉则省略。此简化不是完整任意拓扑等值线追踪。
- 训练点覆盖层压力容差 ±10 kPa、最多500点；样品厚度与压力不完全相同，因此仅供参照。
- 推荐候选为50×50，O2=[8,55]、u=[0.1,150]，流速对数等距。
- 推荐边界权重：`0.1+0.9 exp(-((p-0.5)/0.25)²)`；稀疏权重：`1+clip(nearest_distance/0.25,0,1)`；原始得分=概率SD×边界权重×稀疏权重，除以最佳候选得分归一化。
- 多样性在归一化 O2/log(flow) 坐标中贪心保留欧氏距离≥0.10的点，推荐k=1–20，默认5。score是采集函数，不是成功概率或NASA实际实验排程。
- SHAP 使用所有成员的 raw、tree_path_dependent 值，按成员平均；全局最多128个训练样本、seed42，归一化平均绝对贡献；两个目标分别缓存。
- `confidence=low`：不在局部支持域或分类概率SD≥0.15；`high`：在支持域且SD<0.08、总log速度SD<0.30；其余medium。
- `regime=burning` 当且仅当平均熄灭概率<0.5；其余子类沿用物理标签，若物理仍判burning则按最优流速左右指示，属于解释性启发式。
- HTTP 输入范围：O2 5–100%、P 10–150kPa、u 0–200cm/s、thickness 0.01–10mm。它们是接口工作范围，并非物理安全范围。

机制参考：[NASA U形边界](https://ntrs.nasa.gov/citations/20230000860)、[NASA 对向流熄灭](https://ntrs.nasa.gov/citations/20040053557)。实现中的数值公式仍是本项目自行选择的近似，未宣称复现文献实验。

## v0.2研究决策服务新增假设

- 批量预测最多256点，和原单次预测共用序列化器；模型仍为同一20成员集成，基础学习算法未改变。
- 场景输入容差默认±1个O2百分数、±2kPa、±1cm/s；三者上限分别10/20/20。128个独立均匀扰动（可选32–512）、seed42，再加8个角点。输入盒与合法API域相交；固定维度会产生重复角点，sample_count报告实际评估行数。
- 材料对比使用库默认厚度；大气对比保留当前材料/厚度，使用预设的假定流速。敏感度是输入盒低/高端的局部有限差，不代表因果效应。
- 约束搜索默认每轴10点，可选5–16点，固定维度只取1点；流速用log1p等距、氧/压力线性等距，域内当前条件另行加入去重。
- 每个候选的目标统计量是中心及8角点的**成员概率下分位最小值**；默认目标0.9。支持域过滤默认开启，要求中心/角点都受支持。角点只采样盒的顶点，不保证盒内部最坏值已被找到。
- 改动成本为三控制变量原始值差除以各请求范围宽度后的欧氏长度；固定轴忽略成本但仍报告delta。Pareto目标为成本小、最小成员下分位大；严格支配定义保留同目标值的并列设置。完整前沿超过20个时等索引取最多20个，报告原始数量和截断标志。
- 信息实验设计默认40×40候选、O2=[8,55]、flow=[0.1,150]，流速log1p等距；分辨率10–60，推荐k=1–20。信息代理是`H(mean(p_m))-mean(H(p_m))`，熵单位bits，0log0按极限0处理；bootstrap不被假定为严格Bayesian后验。
- acquisition可选信息代理（默认）、预测熵（boundary）或成员标准差（disagreement）。其后乘`0.1+0.9exp(-((p-.5)/.25)^2)`与`1+clip(distance/.25,0,1)`，只在eligible集合内归一化。
- 实验设计排除支持距离≤0.025的已测近邻，距离使用现有模型的四维物理尺度。多样性要求请求范围归一化O2/log1p-flow坐标距离≥0.10；不满足时可少于k个。全部eligible原始得分≤1e-12时返回空点列表及说明。
- 新模型卡保留10个等宽折外概率箱，空箱均值为null；ECE为箱内平均概率与事件比例的绝对差按count加权。分箱Brier重构项为reliability-resolution+uncertainty，另报binning_residual，使总分可核对。按材料/实验切片无燃烧或单类时，不定义的指标返回null。
- 数据指纹保留重复行、忽略行顺序，浮点使用精确float.hex；CSV解析造成1ULP变化也会改变身份。物理指纹包含LF规范化源码、当前常数和材料热属性；另有训练配置（含依赖版本）、拟合树文本及log噪声指纹。model_id组合四类SHA256；它不是真实性签名。
- 新指纹模型在load/save/启动时核对运行时物理、材料、推理常量、训练数据和树身份；不匹配要求重训。legacy无指纹可推理但不宣称验证证据；外部Predictor不被强行套用本模型的身份schema。

科学方法来源：[BALD原始论文](https://arxiv.org/abs/1112.5745)、[sklearn校准与Brier说明](https://scikit-learn.org/stable/modules/calibration.html)。这些方法依据不对本项目近似物理或当前合成数据的真实性背书。

## v0.3真实NASA观测与训练约定

- NASA-CR-182185 TableI共13条件：8个直接测速率、3个观测熄灭、2个左删失速率。后两项保留原始证据但不入完整目标训练CSV；不填零，也不改成熄灭。
- 厚度按原文半厚度0.0038cm×2转换为全厚度0.076mm；1atm按名义值换算101.325kPa；rate cm/s×10转mm/s；gravity_g=0是微重力名义编码，不是实测绝对零重力。
- 流速取fuel speed，即移动样品相对静止氧化剂的速度。characteristic velocity含目标火焰速度，不能作输入，否则泄漏。
- 观测窗5.18秒；未灭标签是窗末右删失生存，不意味着长期不熄灭。混合模型只用于研究展示，这个不同观测窗限制必须公开。
- 报告全部11可用条件归同一experiment_id/campaign NASA-CR-182185，整个报告在外层同折留出。最终fit可见它，但外部/OOF报告不能用最终fit训练集预测替代。
- 原报告纸样99%cellulose/1%polyamide，映射到cellulose_thin类别，行内保留真实厚度；现有库密度/比热/热解温度仍是近似，不标作该报告的直接热物性测量。
- NASA实际训练覆盖仅一个薄片材料与一个名义压力；所有其它材料/压力的数据支持可能来自synthetic，不因全局data_source=mixed就成为NASA实测验证。
- PSI25的129条目录、BASS-II39个厚PMMA速度阶段和2个薄PMMA边界只作证据：缺失stage O2、完整目标、不同流向/几何等不能补造。仪器fan display为电压×10，不能当cm/s；air display有约1min响应滞后。
- 原始值快照由PDF渲染逐行核验并绑定官方源SHA256；Git对curated快照禁用换行转换，以保持跨机器字节一致。SHA256不是身份认证或NASA模型批准。
- 原synthetic-only模型外部NASA覆盖率37.5%；v0.3整篇NASA留出覆盖率也为37.5%。真实域迁移不足必须单列，聚合93.48%不是NASA覆盖率。
